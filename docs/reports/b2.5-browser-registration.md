## What changed

**Ownership (`crates/browser-host/src/registration.rs`).** An entry belongs to this installation only when its
manifest names `com.downova.host` **and** its `path` is this installation's host. A Windows registry value belongs to
the owner of the manifest it points to. Every entry is classified as `absent`, `ours`, `stale`,
`other_installation`, `unreadable` or `foreign`.

- **`register` / `repair`** (repeatable):
  - checks the manifest and the registry value before writing anything;
  - writes over `absent`, `ours` and `stale`;
  - refuses another live installation or an unreadable file unless `--replace`, and never replaces a different host;
  - writes atomically, mode `0644` on Unix;
  - on Windows, undoes a new manifest when the registry write fails.
- **`unregister`** removes only `ours` entries and lists everything it kept. `--host-path` names the installation;
  the default is the running executable.
- **`status --json`** reports the manifest, its owner, and on Windows the registry value and owner.
- **Per browser:** each browser is handled on its own; one failure gives exit 3 without stopping the others.
- **Refused locations:** relative paths, AppImage mounts, `/Volumes/…` (disk images) and `…/AppTranslocation/…`.
- **Locations:**
  - Chrome for Testing added (`google-chrome-for-testing`, `Google/ChromeForTesting`; Chrome 146+);
  - Linux honours `$XDG_CONFIG_HOME`;
  - on Windows Chrome's channels and Chrome for Testing share Google's key, and therefore one manifest.

**Installer and first launch.**
- **NSIS** (`installMode: currentUser`): `installer-hooks.nsh` runs `register --browser chrome --browser edge` after
  install, and `unregister … --host-path "$INSTDIR\dm-browser-host.exe"` before uninstall.
- **Desktop** (`apps/desktop/src-tauri/src/browser_setup.rs`):
  - on launch it runs the **sibling** `dm-browser-host register` in the background (no crate dependency, per
    `docs/project-structure.md`);
  - it records the outcome in `<data>/browser-setup.json` and repeats only for a new location or version, or after an
    incomplete attempt;
  - `DOWNOVA_SKIP_BROWSER_SETUP=1` turns it off.

  This is the per-user setup for the MSI, macOS (after moving to Applications) and Linux `.deb`. No root package
  script writes per-user files.
- **No uninstall hook** (MSI, macOS Trash, `dpkg -r`): the documented step is `dm-browser-host unregister`
  ([setup](../setup.md#browser-integration-after-installing-b25-adr-0014)). Leftovers are `stale` and are taken over by
  the next install. The host still never starts the service: the app must be opened once after install.

**Harness.**
- `scripts/e2e/chrome-handoff.mjs`:
  - `--installed-dir --data-dir --download-dir --product-registration --handoff-only --menu-url --menu-sha256`;
  - the development registration uses `--replace` and restores the previous value;
  - Windows Edge gets `--edge-skip-compat-layer-relaunch`. Without it, Edge relaunched itself and the DevTools pipe
    was lost ("browser exited"), which is why real Edge had never run before.
- `scripts/smoke/packaged-smoke.mjs`:
  - steps R0–R5 and D0/D2;
  - existing steps set `DOWNOVA_SKIP_BROWSER_SETUP=1`;
  - the e2e child is awaited asynchronously, because a `spawnSync` blocked the smoke's own fixture server (first local
    run: `NETWORK_OFFLINE`, fixed).

## Not verified / limitations

- **macOS and Linux:** the new code paths are written and unit-covered on Windows only. Not yet run:
  - the first-launch registration from `/Applications` or `/usr/bin`;
  - `$HOME` isolation with `--user-data-dir` set to the browser's default directory;
  - mode `0644`;
  - D0 (the documented unregister).

  CI package smoke on the pushed tree is the evidence still to come. Linux runs the packaged smoke on ubuntu-22.04
  only.
- **MSI:** the smoke uses an administrative extract. A real per-machine MSI install, followed by a per-user first
  launch, was not run.
- **Edge on macOS/Linux:** runs only where CI images have Edge; otherwise the R3 Edge row says `unavailable`.
- **Store IDs:** unknown; only the development ID is allowlisted. Firefox, Snap/Flatpak browsers and system-wide
  registration are out of scope.
- **Manual tray checks** (B2.2) are still not performed. **B2 has not exited:** that needs CI evidence on macOS and
  Linux, and a recorded human right-click.
- Two headless Edge processes from a diagnostic probe (temporary `edge-probe-*` profiles) were left running on the
  local machine; stopping them was not permitted from this session.
